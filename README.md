# Измерение скорости загрузки

Скрипт на Node.js скачивает данные по указанному URL 10 раз подряд, каждый раз дожидаясь полного ответа. Затем выводит общий объём данных, среднее время запроса и скорость скачивания.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости не нужно.

Откройте терминал в папке проекта и выполните:

```sh
node speedtest.js "https://example.com/large-file.jpg"
```

Вместо примера укажите прямую ссылку на файл или картинку. Ссылку оставьте в кавычках.

## Результаты

- Объём данных — в байтах.
- Среднее время запроса — в секундах.
- Скорость скачивания — в МБ/с (1 МБ = 1 000 000 байт).

Скорость считается как общий объём данных, делённый на суммарное время запросов. Результат зависит от выбранного сервера и соединения.

Если запрос завершится с ошибкой или займёт больше 30 секунд, скрипт остановится и выведет сообщение об ошибке.
